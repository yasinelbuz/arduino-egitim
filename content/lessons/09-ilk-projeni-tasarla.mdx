## Proje: kişisel ışık işaretin

Bir butona basınca **kendi ışık ritmini** çalan bir kart tasarla. Malzemelerin önceki derslerle aynı: Arduino Uno R3, USB kablosu, buton ve bağlantı kabloları.

## Önce kâğıt üzerinde düşün

1. İşaretin kaç kısa ve kaç uzun ışıktan oluşacak?
2. Butona basılmadığında LED ne yapacak?
3. Butonu basılı tutarsan ritmin tekrar etmesini ister misin?

## Başlangıç kodun

Önceki buton bağlantısını kullan. Aşağıdaki örnek, butona basılı tuttuğun sürece iki kısa ve bir uzun ışık çalar.

```cpp
void setup() {
  pinMode(2, INPUT_PULLUP);
  pinMode(LED_BUILTIN, OUTPUT);
}

void isikYak(int sure) {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(sure);
  digitalWrite(LED_BUILTIN, LOW);
  delay(250);
}

void loop() {
  if (digitalRead(2) == LOW) {
    isikYak(200);
    isikYak(200);
    isikYak(800);
    delay(1000);
  }
}
```

<Callout title="Gözlem yapalım">
  Ritim başladıktan sonra butonu bıraksan bile o ritim tamamlanır. Çünkü program
  delay() ile beklerken butonu yeniden okumaz. Bir sonraki loop() turunda
  yeniden kontrol eder.
</Callout>
