## Tekrarı kolaylaştıran bir yardımcı

Aynı işi birkaç kez yapacağız. Bu yüzden `isikYak` adında küçük bir **fonksiyon** yazalım. Bu yardımcı, verdiğimiz süre boyunca ışığı yakacak ve sonra söndürecek.

```cpp
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void isikYak(int sure) {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(sure);
  digitalWrite(LED_BUILTIN, LOW);
  delay(250);
}

void loop() {
  isikYak(200);
  isikYak(200);
  isikYak(800);
  delay(1500);
}
```

## Kendi işaretini tasarla

1. Kaç kısa, kaç uzun ışık istediğine karar ver.
2. `loop()` içindeki `isikYak()` satırlarını değiştir veya yenilerini ekle.
3. Arkadaşından ritmi tahmin etmesini iste.

`int sure`, yardımcı fonksiyonumuzun aldığı tam sayı değeridir. `isikYak(800)` dediğimizde `sure` değeri 800 olur.
